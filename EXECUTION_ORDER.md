# Execution Order for AURORA-TWETF Reproducibility Package

This file describes the recommended execution order for reproducing the manuscript results for:

**Diagnosing forecast-to-allocation effects in Taiwan ETF portfolios: cash exposure, uncertainty-aware allocation, and downside-risk control**

The repository contains more than 23 notebooks. Reviewers do **not** need to inspect every notebook manually. The notebook sequence below explains which notebooks generate the key data, tables, figures, and diagnostic outputs used in the manuscript.

---

## 1. Important notes before running

### Data access

Raw market data are downloaded from public yfinance-accessible sources. Raw data redistribution rights may depend on the original providers, so raw data files may not be included in the repository.

The data-ingestion notebooks reconstruct the required price panels and return matrices from public sources.

### Evaluation window terminology

The manuscript refers to the main test period as the:

319-trading-day aligned out-of-sample evaluation window

This window spans:

2024-11-27 to 2026-03-25

Some older file names and pipeline outputs may contain the term strict_test. In the manuscript and Supplement, this should be interpreted as the same aligned out-of-sample evaluation window unless otherwise noted.

### Source-aware outputs

The repository contains outputs generated by several analysis pipelines. These outputs are intentionally not merged blindly because the same strategy or benchmark label can refer to different return-generation pipelines, alignment rules, warm-up conventions, transaction-cost timing, or first-rebalance handling.

The main AURORA-versus-ROMA comparison uses the source-aware return matrix generated by the unified comparison pipeline. Standalone diagnostic pipelines are used for mechanism attribution, ablations, constant-λ controls, equivalence diagnostics, and robustness checks. These diagnostic outputs are not treated as numerically interchangeable with the main source-aware comparison unless explicitly bridged.

### Reproducibility metadata

The repository includes machine-readable reproducibility metadata, including:

reproducibility/OUTPUT_MANIFEST.csv
reproducibility/pipeline_metadata_AURORA_TWETF.csv
reproducibility/random_seeds.md
reproducibility/validation_reports/

The pipeline metadata file documents signal lags, warm-up rules, first valid return dates, first invested dates, transaction-cost conventions, cash-return conventions, price-field conventions, and claim use for each major analysis pipeline.

## 5. Interpretation notes

AURORA-TWETF is a diagnostic forecast-to-allocation attribution study, not a financial-advice system and not a claim of generally superior ETF trading performance.

The main supported interpretation is:

In the evaluated Taiwan ETF case, AURORA10-UAMV-B improves selected risk-adjusted and downside-risk metrics relative to ROMA-P4 in the main source-aware comparison, but the mechanism diagnostics indicate that the AURORA-compatible diagnostic reconstruction is primarily driven by defensive cash exposure, cash-cap design, and elevated effective risk aversion rather than strong dynamic probability-timing value.

The bridge diagnostic shows high daily-return and drawdown alignment between the main source-aware AURORA series and the diagnostic AURORA reconstruction, but the series are not numerically identical and exact cash-weight alignment is unavailable. Therefore, the mechanism-attribution controls provide strong evidence for the diagnostic reconstruction and supportive, not exact, evidence for the main source-aware AURORA series.
