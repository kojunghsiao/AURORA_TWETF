# Manuscript-Facing Tables and Figures

This folder collects final manuscript-facing tables and figures for the AURORA-TWETF study.

## Folders

- `tables/`: main manuscript table source files where available.
- `figures/`: final manuscript figures, including the drawdown and mechanism-attribution figures where available.
- `supplementary_tables/`: supplementary table source files and key final-run diagnostic tables.

## Important source folders

Two final run folders support central manuscript claims:

- `outputs/AURORA_TWETF/equivalence_lambda_cash_sensitivity/run_20260722_133503/`
- `outputs/AURORA_TWETF/canonical_passive_benchmarks/run_20260723_035525/`

These original run folders are preserved under `outputs/` and should be treated as the authoritative audit trail. The files collected under `manuscript/` are convenience copies for reviewer navigation.
